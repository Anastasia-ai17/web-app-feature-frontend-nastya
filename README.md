# 🍅 **FocusFlow - Приложение для управления временем**

FocusFlow — это веб-приложение, основанное на технике Pomodoro (Помодоро), которое помогает концентрироваться на задачах, отслеживать прогресс и мотивирует пользователя с помощью системы геймификации.

## ✨ **Основные возможности**

- **Таймер Помодоро**: Классический режим 25/5/15 с возможностью гибкой настройки интервалов работы, отдыха и длительных перерывов.

- **Статистика и достижения**: Отслеживание времени фокуса за день, неделю и месяц. Система достижений за выполнение определенных целей (например, "Первый фокус", "Мастер циклов").

- **Геймификация и магазин**: Внутренняя валюта (монеты), которую можно заработать за завершенные циклы и ежедневные бонусы. В магазине можно купить уникальные темы оформления, звуки таймера и аватары.

- **Профиль пользователя**: Настройка личных данных, смена пароля и выбор купленных аватаров.

- **Темная/Светлая тема**: Поддержка переключения между режимами отображения.

## 🚀 **Как запустить проект локально**

Проект состоит из двух частей: бэкенда (Django) и фронтенда (React). Для запуска вам понадобятся два открытых терминала.

### *Предварительные требования*

Убедитесь, что у вас установлены:

- Python (3.8+)

- Node.js и npm

- uv (современный менеджер пакетов для Python)

### *Шаг 1: Запуск Бэкенда (Терминал 1)*

1. Откройте первый терминал и перейдите в корневую папку проекта (туда, где находится файл manage.py).

2. Запустите сервер разработки Django с помощью uv (он автоматически создаст виртуальное окружение и установит все зависимости):

`uv run manage.py runserver`

*Бэкенд будет доступен по адресу: http://127.0.0.1:8000/*

### *Шаг 2: Запуск Фронтенда (Терминал 2)*

1. Откройте второй терминал и перейдите в папку с React-приложением:

`cd pomodoro_react`

2. Установите зависимости npm:

`npm install`

3. Запустите приложение React:

`npm start`

*Фронтенд будет доступен по адресу: http://localhost:3000/*
